## 🧪 Формат финальной работы

- Мини-проект (ДЗ-4): выбор близкой для себя задачи.
- Допускается собственная тема или одна из предложенных тем (например, advanced-алгоритмы, соревнования и т.п.).
- Защита: небольшая презентация с описанием среды, алгоритма и результатов.

### 🧩 Варианты проектов

| # | Название | Описание |
| :---: | :--- | :--- |
| **1** | **Имитационное обучение (SQIL)** | Разберите [блокнот](projects/SQIL.ipynb) с реализацией метода SQIL, заполните пропущенные фрагменты и добавьте обучение на основе одного из [датасетов MuJoCo](https://minari.farama.org/main/datasets/mujoco/). Проведите обучение для всех уровней экспертов (*expert*, *simple*, *medium*) и проанализируйте результаты. |
| **2** | **Розовый шум** | Ознакомьтесь со [статьёй](https://openreview.net/forum?id=hQ9V5QN27eS), запустите предложенную реализацию (ссылка приведена в тексте статьи). Выберите не менее трёх сред (одна из которых должна быть новой, не использованной в статье), проведите эксперименты и определите, какой тип шума даёт лучшие результаты. |
| **3** | **Контекстные бандиты** | Выполните задания из [блокнота](projects/Bandits.ipynb), посвящённого контекстным бандитам. |
| **4** | **Hindsight Experience Replay (HER)** | Разберите [блокнот](projects/HER.ipynb) с реализацией DDPG+HER. Реализуйте стратегии переобозначения целей (*future*, *final*, *episode*), проведите эксперименты с каждой из них и проанализируйте полученные результаты. |
| **5** | **Своя среда** | Реализуйте собственную среду и опишите её подробно (по аналогии с первым домашним заданием). Подберите подходящий RL-алгоритм (например, DQN, PPO или SAC) и оптимальные гиперпараметры. Проведите обучение и анализ результатов. |
| **6** | **Упрощённый Deep Q-Learning (PQN)** | Ознакомьтесь со статьёй [Simplifying Deep Temporal Difference Learning](https://arxiv.org/abs/2407.04811). Реализуйте или адаптируйте базовый DQN для сред CartPole и Acrobot, после чего последовательно исследуйте влияние основных компонентов алгоритма: replay buffer, target network и нормализации. Сравните несколько вариантов алгоритма по скорости и стабильности обучения и проанализируйте, какие компоненты действительно необходимы. |
| **7** | **Потеря пластичности в RL** | Исследуйте способность RL-агента адаптироваться к изменению среды во время обучения. Обучите DQN или PPO на одной конфигурации CartPole и LunarLander, а затем измените параметры среды, например длину шеста в CartPole или гравитацию в LunarLander. Сравните обычное продолжение обучения с несколькими простыми способами восстановления пластичности, например переинициализацией части нейронной сети. Проанализируйте скорость адаптации после изменения среды. |
| **8** | **Trust-region проекции вместо PPO clipping (TROLL)** | Ознакомьтесь со статьёй [TROLL: Trust Regions improve RL for LLMs](https://openreview.net/forum?id=X9D5MVpPJ9). Исследуйте, может ли явная проекция распределения действий в KL-окрестность старой стратегии заменить clipping в PPO на средах с дискретными действиями. Сравните стандартный PPO и вариант с проекцией по качеству, стабильности и эффективности использования данных. При ограниченных ресурсах можно использовать MountainCar и LunarLander с дискретными действиями. [Подробное задание](projects/TROLL.md). |
| **9** | **Обучение модели в стиле Jev игре Sokoban** | Дообучите небольшую модель Kev-0.6B с помощью RL для игры в Sokoban по текстовым наблюдениям. Сравните модель до и после обучения с агентом с небольшой нейросетью, обученным с нуля, исследуйте влияние представления поля и проверьте обобщение на новые уровни. [Подробное задание](projects/Sokoban.md). |
| **10** | **Собственный проект** | Можете предложить свой вариант проекта. Перед началом работы обязательно согласуйте его. |

## ✅ Условия зачета

- `Зачет с отличием` - все ДЗ сданы до дедлайнов и отлично выполнен мини-проект (ДЗ-4).
- `Обычный зачет` - все ДЗ сданы в срок и хорошо выполнен мини-проект (ДЗ-4).
- В остальных случаях - зачет не выставляется.
