## 🧪 Формат финальной работы

- Мини-проект (ДЗ-4): выбор близкой для себя задачи.
- Допускается собственная тема или одна из предложенных тем (например, advanced-алгоритмы, соревнования и т.п.).
- Защита: небольшая презентация с описанием среды, алгоритма и результатов.

## ✅ Условия зачета

- `Зачет с отличием` - все ДЗ сданы до дедлайнов и отлично выполнен мини-проект (ДЗ-4).
- `Обычный зачет` - все ДЗ сданы в срок и хорошо выполнен мини-проект (ДЗ-4).
- В остальных случаях - зачет не выставляется.
